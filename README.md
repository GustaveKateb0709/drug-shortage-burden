# The unequal burden of essential drug shortages — replication package

Replication code for: *The unequal burden of essential drug shortages: stock composition,
market concentration, and disease-burden distribution in the public U.S. shortage list*.

All inputs are public downloads; no restricted data and no individual-level data are used.

## Data sources

| File | Source |
|---|---|
| openFDA drug shortages download file | https://open.fda.gov/data/downloads/ (snapshot 2026-09-11) |
| openFDA NDC directory | https://download.open.fda.gov/drug/ndc/ |
| openFDA Drugs@FDA | https://download.open.fda.gov/drug/drugsfda/ |
| openFDA Orange Book | https://download.open.fda.gov/drug/orangebook/ |
| CDC WONDER D140 / D76 mortality extracts | https://wonder.cdc.gov/ (browser export; see src/wonder_extract*.py) |
| CDC/ATSDR SVI 2022 (county) | https://svi2.cdc.gov/ |

MD5 checksums for every raw download are recorded in `artifacts/manifest.json`
(regenerated by `src/fetch_data.py`).

## Pipeline

```
python3 src/fetch_data.py            # 1. download raw files + manifest (needs network)
python3 src/build_pipeline.py        # 2. parse/link -> data/*.parquet, coverage table
python3 src/audit_and_plot.py        # 3. five data checks + Figure 1
python3 src/estimate_h1h2.py         # 4. H1'/H2 main models -> Table 1
python3 src/robustness_h1h2.py       # 5. spec curve, permutation, worst-case bounds
python3 src/estimate_h3.py           # 6. equity gradients (sub-row era, kept as audit)
python3 src/estimate_h3_chapter.py   # 7. chapter-panel direct estimates (operative)
python3 src/robustness_h3_chapter.py # 8. yearly/LOO/permutation/weighting battery
python3 src/plot_public_appendix.py  # 9. Appendix Figures A1/A3/A5 (PNG+TIF+PDF)
python3 src/plot_public_figs_b.py    # 10. Figure 2 + Appendix A2/A4/A6/A7 (PNG+TIF+PDF)
python3 src/make_fig1_tif.py         # 11. Figure 1 submission TIFF (from its vector PDF)
```

Small derived inputs shipped for the figure stage so it runs without re-estimation:
`results/table3_chapter_panel.xlsx`, `results/table5_robustness.xlsx`,
`artifacts/h3_results.json`, `artifacts/robustness_h3.json`,
`artifacts/robustness_h3_chapter.json`, `artifacts/robustness_results.json`.
`figures_public/A2_digitized_source.json` is a shipped provenance artifact: A2's
original generator is not reconstructable from the saved parquet files, so its
plotted values were pixel-digitized from the delivered figure
(`src/a2_digitize_source.py`; QC overlay included). No number is invented.

CDC WONDER extracts use browser-session export scripts (`src/wonder_extract*.py`)
because the XML API forces national-level output for state queries; queries respect
the vendor's rate limit (>=2 minutes between queries). SVI state aggregation:
`src/svi_state.py`.

## Notes

- Raw downloads (~520 MB) are not stored in this repository; `fetch_data.py` refetches them.
- Source code comments are in English; a few shipped result files keep their
  original (Chinese-labelled) column names for provenance — the figure scripts
  read those names as data keys.
- The pipeline is standard Python (pandas / statsmodels / lifelines / matplotlib)
  and runs on CPU in minutes.
